# NoTextGrain Lab

**Эксперимент для Codex: проверяем способ ослабить текстовые водяные знаки OpenAI без смены модели.**

Скилл уже умеет автоматически создавать ответ и сохранять его в готовый файл.
**Помогает ли это обойти textGrain — пока неизвестно.** Для проверки нужен
официальный детектор; доступа к нему у проекта сейчас нет.

## Что делает скилл

Вы задаёте обычный вопрос в Codex. Ваша текущая модель пишет ответ небольшими
частями, а программа на компьютере соединяет их в обычный текст. Вместо длинного
сообщения в чате вы получаете ссылку на файл с ответом. Его можно открыть,
скопировать или сохранить.

- Не нужна другая модель, Ollama, отдельный сервер или ключ API.
- После установки режим включается в новых локальных чатах Codex по умолчанию.
- Ответ может готовиться дольше: в двух наших примерах потребовалось около 40–62 секунд.
- **Обычный ChatGPT в браузере пока не поддерживается.**

Идея эксперимента: формат текста во время генерации отличается от готового
ответа. Мы проверяем, может ли это ослабить маркировку. Само соединение частей
не доказывает, что водяной знак исчез.

## Как попробовать

Нужны **Codex на компьютере и Python 3.10 или новее**.

1. [Скачайте ZIP](https://github.com/HexCine/no-textgrain/archive/refs/heads/main.zip) и распакуйте его.
2. Откройте терминал в распакованной папке и выполните:

   ```sh
   python setup.py install
   ```

3. Начните **новый чат Codex** и задайте обычный вопрос.

На macOS/Linux команда Python может называться `python3`.
Установка сохраняет резервную копию ваших стартовых инструкций. Она не меняет
модель или разрешения Codex. Если локальные команды или запись файлов запрещены,
скилл не сможет собрать ответ. Мы не рекомендуем отключать защиту ради него.

Признак работы скилла — ссылка на созданный файл с ответом. Это **не подтверждение
обхода водяного знака**. Серверный переключатель textGrain скилл не отключает.

## Как отключить

Для одного ответа напишите: **«Ответь обычным текстом прямо в чате»**.
Чтобы убрать режим по умолчанию, выполните в папке проекта:

```sh
python setup.py remove
```

Затем начните новый чат. Ваши остальные инструкции сохранятся.

<details>
<summary>Ручной запуск и проверка установки</summary>

Установить только скилл, без включения во всех новых чатах:

```sh
python setup.py install --manual
```

Вызывать его можно командой `$fragment-text`. Это прежнее техническое имя скилла;
оно сохранено, чтобы не сломать существующие установки.

Проверить установку:

```sh
python setup.py status
```

Если скилл уже установлен, для обновления сначала выполните `remove`, затем
`install` из новой версии.

</details>

## Как мы собираемся проверить обход

Нашли [официальную форму доступа к текстовому детектору](https://openai.com/form/content-provenance-api/).
Подготовили [описание эксперимента для заявки и критерии проверки](DETECTOR_ACCESS.md).
Заявка ещё не отправлена: форму заполняет владелец проекта своими контактными
данными и достоверными сведениями об организации. Получение доступа не гарантировано.

После получения доступа нужны маркированные образцы и сравнение обычных ответов
с ответами скилла. До этого проект остаётся экспериментом: **подтверждённого
способа обхода здесь пока нет**.
